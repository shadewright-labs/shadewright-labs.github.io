# Security policy

This repository holds the Shadewright Labs organisation site: static HTML and CSS published with GitHub Pages.

## Reporting a problem with the site

Report it privately through GitHub: [open a security advisory for this repository](https://github.com/shadewright-labs/shadewright-labs.github.io/security/advisories/new). Do not open a public issue or pull request for it.

Examples of what belongs here: a page that loads something from another origin, a way around the page's Content-Security-Policy, a broken or hijackable link, or a problem in the workflows that publish the site.

## Reporting a problem with a product

A problem in Shadewright, Sablecourt or another product goes to that product's own repository, which has its own security policy and advisory form:

- Shadewright: https://github.com/shadewright-labs/shadewright/security/policy
- Sablecourt: https://github.com/shadewright-labs/sablecourt/security/policy
